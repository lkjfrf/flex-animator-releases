# Flex Animator

내 PC에서 쇼츠 애니메이션을 만드는 윈도우 앱. 이 저장소에는 **설치 파일과 업데이트 정보만** 있어요.

## 설치
1. **[FlexAnimator-Setup.exe 받기](https://github.com/lkjfrf/flex-animator-releases/releases/latest/download/FlexAnimator-Setup.exe)** (4MB)
2. 실행하면 최신 버전을 내려받아 공식 서명을 확인한 뒤 설치하고 바로 켜요.
   - 윈도우가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 눌러 주세요(아직 코드 서명 인증서가 없어서 떠요).
3. 처음 켜면 **작업 폴더**와 **AI 연결**(Claude 구독 / ChatGPT 구독 / API 키)을 골라요. 필요한 프로그램은 '이 PC 준비' 창이 점검하고 설치를 도와줘요.
4. 그 뒤로는 새 버전이 나오면 **알아서 업데이트**돼요(작업 중이면 끝난 뒤에).

설치 프로그램 없이 받으려면 [최신 릴리스](https://github.com/lkjfrf/flex-animator-releases/releases/latest)의 `FlexAnimator_x.y.z_x64-setup.exe`를 받아도 돼요.
