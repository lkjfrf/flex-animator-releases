# Flex Animator

내 PC에서 쇼츠 애니메이션을 만드는 윈도우 앱. 이 저장소에는 **설치 파일과 업데이트 정보만** 있어요.

## 설치
1. [최신 릴리스](https://github.com/lkjfrf/flex-animator-releases/releases/latest)에서 `FlexAnimator_x.y.z_x64-setup.exe`를 받아 실행해요.
2. 설치가 끝나면 Flex Animator가 켜져요. 창을 닫아도 오른쪽 아래 트레이에서 계속 돌아가요(완전히 끄기: 트레이 아이콘 오른쪽 클릭 → 종료).
3. 그 뒤로는 새 버전이 나오면 **알아서 업데이트**돼요(작업 중이면 끝난 뒤에).

## 필요한 것 (아직 자동 설치 전)
- Windows 10/11 64비트
- [Claude Code](https://claude.com/claude-code) 로그인 — 마스터(대화·대본)
- Python 3.10+ 와 `pip install faster-whisper edge-tts pillow` — 목소리·받아쓰기·의상
- ffmpeg (PATH에)
- Codex 앱 로그인 — 새 의상 그리기(ChatGPT 구독)
